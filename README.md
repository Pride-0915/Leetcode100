# 力扣 Hot 100 题解库（C++）

按题型收录力扣 Hot 100 的解题思路、复杂度分析和 C++ 实现。每道题单独成文，便于检索、复习和持续补充。

## 入口

- [题目索引](题目索引.md)：按题型查看题目和收录进度
- [题解模板](题解模板.md)：新增题解时使用的统一格式
- [题解目录](题解/)：各题型的题解文件

## 题解约定

1. 题解以力扣 Hot 100 为范围，题目名称和编号以 LeetCode 页面为准。
2. 每篇包含题意概括、核心思路、关键步骤、复杂度、C++ 代码和易错点。
3. 代码默认按力扣提交格式书写；题目给定的数据结构不重复定义。
4. 先完成基础解法，再补充优化解法；关键结论尽量解释原因，不只贴代码。
