# 206. 反转链表

- 题目链接：[LeetCode 206](https://leetcode.cn/problems/reverse-linked-list/)
- 难度：简单
- 标签：链表、双指针、迭代

## 题意概括

给定单链表的头节点 `head`，原地反转链表，并返回反转后的新头节点。链表可以为空，节点值不影响反转过程。

## 核心思路

使用迭代双指针：`prev` 指向已经反转部分的头节点，`cur` 指向当前待处理节点。每轮先用临时指针保存 `cur->next`，再将当前节点的 `next` 指向 `prev`，最后将两个工作指针向前移动。

关键是修改 `cur->next` 之前先保存原来的后继节点，否则后续遍历会丢失剩余链表。

## 解题步骤

1. 初始化 `prev = nullptr`、`cur = head`。
2. 当 `cur` 不为空时，依次保存原后继节点、反转当前节点指针、移动 `prev` 和 `cur`。
3. 遍历结束时，`prev` 指向反转后的新头节点，返回 `prev`。

## 复杂度

- 时间：$O(n)$，每个节点处理一次。
- 空间：$O(1)$，只使用常数个额外指针。

## 我的代码

```cpp
class Solution {
public:
ListNode* reverseList(ListNode* head) {
ListNode* prev = nullptr;
ListNode* cur = head;

while (cur != nullptr) {
    ListNode* nextTemp = cur->next;
    cur->next = prev;
    prev = cur;
    cur = nextTemp;
}

return prev;
}
};
```

## 标准代码（正确且最优）

```cpp
class Solution {
public:
    ListNode* reverseList(ListNode* head) {
        ListNode* previous = nullptr;
        ListNode* current = head;

        while (current != nullptr) {
            ListNode* nextNode = current->next;
            current->next = previous;
            previous = current;
            current = nextNode;
        }

        return previous;
    }
};
```

## 易错点

- 忘记在改写 `cur->next` 前保存原后继节点，会导致剩余链表无法继续访问。
- 反转后原来的 `head` 已成为尾节点，应该返回 `prev`，不能返回 `head`。
- 空链表时循环不会执行，最终返回 `nullptr`；单节点链表也无需特殊分支。
- `head` 是指针，访问成员要使用 `head->next`，不能写成 `head.next`。
- 本题无需哨兵节点；若使用 dummy，返回值应是 `dummy->next`，而不是 `dummy`。
- `prev` 与 `cur` 每轮同步向前推进，不是快慢指针，不要混淆其含义。

## 复习提示

反转链表记住：先存 `next`，再改箭头，最后移动 `prev` 和 `cur`。
