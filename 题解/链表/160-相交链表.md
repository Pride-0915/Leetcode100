# 160. 相交链表

- 题目链接：[LeetCode 160](https://leetcode.cn/problems/intersection-of-two-linked-lists/)
- 难度：简单
- 标签：链表、双指针

## 题意概括

给定两个单链表的头节点，找出它们开始相交的节点；若不相交，返回 `nullptr`。相交指节点身份相同，而不只是节点值相同。

## 核心思路

设两条链表在相交前的长度分别为 `a`、`b`，公共部分长度为 `c`。指针 `pA` 走完 A 后切换到 B，`pB` 走完 B 后切换到 A。这样两者都走过 `a + b + c` 个节点：如果存在交点，会在交点相遇；如果不存在，会同时走到空节点。

## 解题步骤

1. 两个指针分别从两条链表头部出发。
2. 指针到达链表尾部后，切换到另一条链表的头部。
3. 两指针相等时返回该节点；这个节点也可能是 `nullptr`。

## 复杂度

- 个人代码：时间最坏为 $O(mn)$（相同值候选节点较多时），空间为 $O(m)$。
- 标准代码：时间为 $O(m+n)$，空间为 $O(1)$。

## 我的代码

```cpp
class Solution {
public:
    ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
        if (headA == NULL || headB == NULL) {
            return NULL;
        }

        unordered_map<int, vector<ListNode*>> hashMap;
        ListNode* curA = headA;
        while (curA != NULL) {
            hashMap[curA->val].push_back(curA);
            curA = curA->next;
        }

        ListNode* curB = headB;
        while (curB != NULL) {
            int bVal = curB->val;
            if (hashMap.count(bVal)) {
                vector<ListNode*> candidates = hashMap[bVal];
                for (ListNode* nodeInA : candidates) {
                    if (nodeInA == curB) {
                        return curB;
                    }
                }
            }
            curB = curB->next;
        }

        return NULL;
    }
};
```

## 标准代码（正确且最优）

```cpp
class Solution {
public:
    ListNode* getIntersectionNode(ListNode* headA, ListNode* headB) {
        ListNode* pointerA = headA;
        ListNode* pointerB = headB;

        while (pointerA != pointerB) {
            pointerA = pointerA == nullptr ? headB : pointerA->next;
            pointerB = pointerB == nullptr ? headA : pointerB->next;
        }

        return pointerA;
    }
};
```

## 易错点

- 不能通过节点值判断相交；要比较节点指针。
- 切换发生在指针走到 `nullptr` 时，不是走到最后一个有效节点时。
- 两表不相交时，指针最终会同时变成 `nullptr`，循环正常结束。

## 复习提示

两指针各走一遍 A+B，抵消两条链表长度差。
