# 94. 二叉树的中序遍历

- 题目链接：[LeetCode 94](https://leetcode.cn/problems/binary-tree-inorder-traversal/)
- 难度：简单
- 标签：栈、树、深度优先搜索

## 题意概括

给定一棵二叉树的根节点 `root`，按照左子树、当前节点、右子树的顺序遍历整棵树，并返回节点值组成的数组。

## 核心思路

使用深度优先搜索完成中序遍历：先访问左子树，再访问当前节点，最后访问右子树。个人代码用成员变量 `res` 保存结果；标准代码则由主函数创建局部数组，并通过引用传入递归函数。

## 解题步骤

1. 从根节点开始递归；遇到空节点时结束当前递归。
2. 依次递归左子树、记录当前节点值、递归右子树。
3. 遍历完成后返回结果数组。

## 复杂度

- 时间：个人代码因每次递归按值返回 `res`，最坏可能产生 $O(n^2)$ 的复制开销；标准代码为 $O(n)$。
- 空间：标准代码的递归栈为 $O(h)$，最坏情况下为 $O(n)$；个人代码按值返回结果还会产生额外复制。

## 我的代码

```cpp
class Solution {
public:
    vector<int> res;

    vector<int> inorderTraversal(TreeNode* root) {
        if (root == nullptr) {
            return res;
        }

        if (root->left != nullptr) {
            inorderTraversal(root->left);
        }
        res.push_back(root->val);
        if (root->right != nullptr) {
            inorderTraversal(root->right);
        }

        return res;
    }
};
```

## 标准代码（正确且最优）

```cpp
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> result;
        dfs(root, result);
        return result;
    }

private:
    void dfs(TreeNode* node, vector<int>& result) {
        if (node == nullptr) {
            return;
        }

        dfs(node->left, result);
        result.push_back(node->val);
        dfs(node->right, result);
    }
};
```

## 易错点

- 遍历顺序必须是左、根、右；调整顺序会变成前序或后序遍历。
- `push_back` 添加的是单个节点值 `node->val`，不是另一个 `vector`。
- 个人代码中的 `res` 是成员变量；如果同一个对象被重复调用，结果会残留，需要在每次调用开始时清空。
- 个人代码的递归调用按值返回整个结果数组，而调用方忽略返回值，会造成不必要的复制；标准代码用 `void` 辅助函数和引用避免该开销。
- 空节点必须先处理，才能访问节点的值或左右子树；左右子树的额外判空在递归函数内部已有处理时可以省略。

## 复习提示

记住“左、根、右”，并用引用把访问到的节点值依次写入同一个结果数组。
