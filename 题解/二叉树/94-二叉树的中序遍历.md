# 94. 二叉树的中序遍历

- 题目链接：[LeetCode 94](https://leetcode.cn/problems/binary-tree-inorder-traversal/)
- 难度：简单
- 标签：栈、树、深度优先搜索

## 题意概括

给定一棵二叉树的根节点 `root`，按照左子树、当前节点、右子树的顺序遍历整棵树，并返回节点值组成的数组。

## 核心思路

使用深度优先搜索递归遍历。中序遍历的关键是先递归左子树，再将当前节点值加入结果，最后递归右子树。自己的提交版用成员变量 `res` 收集结果；推荐写法则由主函数创建局部数组并通过引用传入，避免成员变量残留和递归时不必要的数组拷贝。

## 解题步骤

1. 从根节点开始递归；遇到空节点时结束当前递归。
2. 依次递归左子树、记录当前节点值、递归右子树。
3. 遍历完成后返回结果数组。

## 复杂度

- 推荐写法时间：$O(n)$，每个节点访问一次；个人提交版递归时按值返回累计结果，可能产生 $O(n^2)$ 的数组拷贝开销。
- 推荐写法辅助空间：$O(h)$，递归调用栈深度为树高；最坏情况下为 $O(n)$。个人提交版的返回值拷贝还会额外占用空间。

## 我的提交代码

```cpp
class Solution {
public:
    vector<int> res;

    vector<int> inorderTraversal(TreeNode* root) {
        if (root == nullptr) {
            return res;
        }

        if (root->left != nullptr) {
            inorderTraversal(root->left);
        }
        res.push_back(root->val);
        if (root->right != nullptr) {
            inorderTraversal(root->right);
        }
        return res;
    }
};
```

## 推荐写法（递归 + 引用）

```cpp
class Solution {
public:
    vector<int> inorderTraversal(TreeNode* root) {
        vector<int> result;
        traverse(root, result);
        return result;
    }

private:
    void traverse(TreeNode* node, vector<int>& result) {
        if (node == nullptr) {
            return;
        }

        traverse(node->left, result);
        result.push_back(node->val);
        traverse(node->right, result);
    }
};
```

## 易错点

- 遍历顺序必须是左、根、右；调整顺序会变成前序或后序遍历。
- `push_back` 添加的是单个节点值 `node->val`，不是另一个 `vector`。
- 辅助函数返回类型为 `void`，空节点时直接 `return`；访问节点成员前要先处理空指针。
- 自己的提交版把 `res` 定义为成员变量；如果同一个 `Solution` 对象被重复调用，需要先清空，否则可能混入上一次的结果。推荐写法将结果数组设为局部变量并通过引用传入。
- 自己的提交版在每个递归调用中都返回 `res` 的副本，而调用方没有使用这些返回值；可将递归辅助函数改为 `void`，通过引用共享结果数组。
- `if (root->left != nullptr)` 和右子树的判断可以省略，递归函数内部会处理空指针。

## 复习提示

记住“左、根、右”，并用引用把访问到的节点值依次写入同一个结果数组。
