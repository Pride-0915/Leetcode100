# 20. 有效的括号

- 题目链接：[LeetCode 20](https://leetcode.com/problems/valid-parentheses/)
- 难度：简单
- 标签：栈、字符串

## 题意概括

给定一个只包含圆括号、方括号和花括号的字符串 `s`，判断括号是否按类型正确配对并按正确顺序闭合。空字符串也有效。

## 核心思路

使用栈的后进先出特性。左括号入栈；遇到右括号时，栈顶必须是对应类型的左括号，否则字符串无效。遍历结束后，栈必须为空，表示没有遗留的左括号。

## 解题步骤

1. 创建空字符栈。
2. 遍历字符串：左括号入栈；右括号先检查栈是否为空，再检查栈顶类型并弹出。
3. 遍历结束后，栈为空则返回 `true`，否则返回 `false`。

## 复杂度

- 时间：$O(n)$，每个字符最多入栈和出栈一次。
- 空间：$O(n)$，最坏情况下字符串全部为左括号。

## 我的代码

```cpp
class Solution {
public:
    bool isValid(string s) {
        stack<char> st;

        for (char c : s) {
            switch (c) {
                case '(':
                case '[':
                case '{':
                    st.push(c);
                    break;

                case ')':
                    if (st.empty() || st.top() != '(') return false;
                    st.pop();
                    break;

                case ']':
                    if (st.empty() || st.top() != '[') return false;
                    st.pop();
                    break;

                case '}':
                    if (st.empty() || st.top() != '{') return false;
                    st.pop();
                    break;
            }
        }

        return st.empty();
    }
};
```

## 标准代码（正确且最优）

```cpp
class Solution {
public:
    bool isValid(string s) {
        const unordered_map<char, char> matchingOpen = {
            {')', '('},
            {']', '['},
            {'}', '{'}
        };
        stack<char> openings;

        for (char c : s) {
            if (c == '(' || c == '[' || c == '{') {
                openings.push(c);
                continue;
            }

            auto match = matchingOpen.find(c);
            if (match == matchingOpen.end() || openings.empty() || openings.top() != match->second) {
                return false;
            }

            openings.pop();
        }

        return openings.empty();
    }
};
```

## 易错点

- 遇到右括号时，必须先检查栈是否为空，再访问 `top()`。
- 只检查“栈里有左括号”不够，还要确认类型匹配，例如 `([)]` 无效。
- 遍历结束后必须检查栈是否为空，否则像 `(((` 这样的未闭合左括号会被误判。
- 题目输入只包含六种括号；若扩展到任意字符，标准版需保留 `find()` 的未命中检查，不能直接解引用迭代器。
- 使用数组手动模拟栈时要单独检查栈顶下标边界；本题用 `stack<char>` 可避免这类手动维护错误。

## 复习提示

左括号入栈，右括号匹配并弹栈；栈空且遍历结束才有效。
