# 15. 三数之和

- 题目链接：[LeetCode 15](https://leetcode.cn/problems/3sum/)
- 难度：中等
- 标签：数组、排序、双指针、哈希表

## 题意概括

给定整数数组 `nums`，找出所有和为 `0` 且不重复的三元组。结果中不能出现重复的三元组。

## 核心思路

推荐解法是先排序，再固定第一个数，用左右双指针在剩余区间寻找另外两个数。排序使相同数字相邻，便于跳过重复三元组；三数之和小于 `0` 时移动左指针增大总和，大于 `0` 时移动右指针减小总和。这是更适合本题的最优实现：时间复杂度为 $O(n^2)$，不需要为查找维护哈希表，也更容易正确去重。

哈希法可以作为对照练习，但不应当作本题的最优解。它的平均时间复杂度也为 $O(n^2)$，不过需要 $O(n)$ 额外空间，并有哈希操作和去重的额外开销，实际运行通常不如排序加双指针稳定、简洁。

## 解题步骤

1. 对 `nums` 排序。
2. 从左到右固定 `i`；若当前值与前一个值相同则跳过，若 `nums[i] > 0` 或当前最小三数之和大于 `0` 则提前结束；若当前最大三数之和仍小于 `0`，则跳过这个 `i`。
3. 初始化 `left = i + 1`、`right = n - 1`，当 `left < right` 时计算三数之和。
4. 和为 `0` 时记录三元组，两个指针各移动一次并跳过重复值；和小于 `0` 时移动左指针，和大于 `0` 时移动右指针。
5. 哈希法仅作对照练习：每个 `i` 开始时清空集合，扫描后续元素；先查询补数，再插入当前值，避免同一个元素被重复使用；用集合记录已经输出过的中间值，避免重复三元组。

## 复杂度

- 推荐：排序 + 双指针，时间 $O(n^2)$，额外空间 $O(1)$（不计排序内部栈和输出）。
- 对照：排序 + 哈希表，平均时间 $O(n^2)$，额外空间 $O(n)$，实际常数开销更大。

## 我的代码

```cpp
class Solution {
public:
	vector<vector<int>> threeSum(vector<int>& nums) {
		vector<vector<int>> target = {};
		// 对数组进行预处理
		sort(nums.begin(), nums.end());
		// 固定一个数，再用左右双指针查找另外两个数
		for (int i = 0; i < nums.size() - 2; i++) {
			// 去重，因为数组有序，相同的数只需查询一次
			if (i > 0 && nums[i] == nums[i - 1]) continue;
			// 固定数大于 0 时，后续不可能凑成 0
			if (nums[i] > 0) break;

			for (int l = i + 1, r = nums.size() - 1; l < r;) {
				int temp = nums[i] + nums[l] + nums[r];
				if (temp == 0) {
					target.push_back({nums[i], nums[l], nums[r]});
					l++;
					r--;
					// 左右指针去重
					while (l < r && nums[l] == nums[l - 1]) l++;
					while (l < r && nums[r] == nums[r + 1]) r--;
				} else if (temp < 0) {
					l++;
				} else {
					r--;
				}
			}
		}

		return target;
	}
};
```

## 标准代码（正确且最优）

```cpp
class Solution {
public:
	vector<vector<int>> threeSum(vector<int>& nums) {
		int n = static_cast<int>(nums.size());
		if (n < 3) return {};

		sort(nums.begin(), nums.end());
		vector<vector<int>> result;

		for (int i = 0; i < n - 2; ++i) {
			if (i > 0 && nums[i] == nums[i - 1]) continue;
			if (nums[i] > 0) break;
			if (nums[i] + nums[i + 1] + nums[i + 2] > 0) break;
			if (nums[i] + nums[n - 2] + nums[n - 1] < 0) continue;

			int left = i + 1;
			int right = n - 1;
			while (left < right) {
				int sum = nums[i] + nums[left] + nums[right];
				if (sum == 0) {
					result.push_back({nums[i], nums[left], nums[right]});
					++left;
					--right;
					while (left < right && nums[left] == nums[left - 1]) ++left;
					while (left < right && nums[right] == nums[right + 1]) --right;
				} else if (sum < 0) {
					++left;
				} else {
					--right;
				}
			}
		}

		return result;
	}
};
```

## 哈希表写法（对照练习）

```cpp
class Solution {
public:
	vector<vector<int>> threeSum(vector<int>& nums) {
		vector<vector<int>> result;
		if (nums.size() < 3) return result;

		sort(nums.begin(), nums.end());
		for (int i = 0; i < static_cast<int>(nums.size()) - 2; ++i) {
			// 排序后相同的首元素相邻，只处理一次。
			if (i > 0 && nums[i] == nums[i - 1]) continue;

			unordered_set<int> seen;
			unordered_set<int> emitted;
			for (int j = i + 1; j < static_cast<int>(nums.size()); ++j) {
				// 补数需要在 j 之前出现过，使三数之和为 0。
				int need = -nums[i] - nums[j];
				if (seen.count(need) && emitted.insert(need).second) {
					// seen 只保存 j 之前的数，不会重复使用当前元素。
					// emitted 保证相同三元组只加入一次。
					result.push_back({nums[i], need, nums[j]});
				}
				// 查询后再插入，确保当前元素不能充当自己的补数。
				seen.insert(nums[j]);
			}
		}

		return result;
	}
};
```

## 易错点
- 找到和为 `0` 后要移动左右指针，并跳过相同值，否则会重复记录或循环不前进。
- 外层固定值 `nums[i]` 也要去重；排序后相同值相邻，比较 `nums[i]` 和 `nums[i - 1]` 即可。
- `nums[i] > 0` 的剪枝应放在外层循环中；排序后固定值为正，后续元素不可能让总和回到 `0`。
- `vector` 使用 `.size()`，没有 `.head()` 或 `.length()` 成员。
- `size()` 返回无符号类型，直接用 `nums.size() - 2` 处理过短数组可能下溢；标准代码先检查长度，再转换为有符号下标。
- 哈希法要在每个 `i` 开始时清空集合，并先查询补数、后插入当前值；容器应使用 `unordered_set<int>`，不能把单个整数直接插入 `unordered_map`。
- 哈希法同样需要跳过重复的 `i`；示例用 `emitted` 集合去重，避免相同三元组被重复加入。

## 复习提示

先排序以便剪枝和相邻去重；固定一个数后，优先用左右指针夹逼剩余两数。
