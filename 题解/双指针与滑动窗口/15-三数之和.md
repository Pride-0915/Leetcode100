# 15. 三数之和

- 题目链接：[LeetCode 15](https://leetcode.cn/problems/3sum/)
- 难度：中等
- 标签：数组、排序、双指针、哈希表

## 题意概括

给定整数数组 `nums`，找出所有和为 `0` 且不重复的三元组。结果中不能出现重复的三元组。

## 我的解法

### 解法一：排序 + 双指针（最优）

先排序，再固定第一个数 `nums[i]`，用左右指针 `l`、`r` 在其右侧查找另外两个数。根据三数之和与 `0` 的大小移动指针；找到一组后同时移动左右指针，并跳过相同值，避免重复结果。

1. 排序数组。
2. 固定 `i`，跳过与前一个位置相同的值；当 `nums[i] > 0` 时，后续三数之和不可能为 `0`，可提前结束。
3. 初始化 `l = i + 1`、`r = n - 1`，在 `l < r` 时计算三数之和。
4. 和为 `0` 时记录结果，移动 `l` 和 `r`，再分别跳过重复值；和小于 `0` 时增大 `l`，和大于 `0` 时减小 `r`。

**复杂度**：时间 $O(n^2)$；额外空间通常按 $O(1)$ 计（不计排序内部栈和输出）。

**我的代码（根据截图整理）**：

```cpp
class Solution {
public:
	vector<vector<int>> threeSum(vector<int>& nums) {
		vector<vector<int>> target = {};
		// 对数组进行预处理
		sort(nums.begin(), nums.end());
		// 固定一个数，再用左右双指针查找另外两个数
		for (int i = 0; i < nums.size() - 2; i++) {
			// 去重，因为数组有序，相同的数只需查询一次
			if (i > 0 && nums[i] == nums[i - 1]) continue;
			// 固定数大于 0 时，后续不可能凑成 0
			if (nums[i] > 0) break;

			for (int l = i + 1, r = nums.size() - 1; l < r;) {
				int temp = nums[i] + nums[l] + nums[r];
				if (temp == 0) {
					target.push_back({nums[i], nums[l], nums[r]});
					l++;
					r--;
					// 左右指针去重
					while (l < r && nums[l] == nums[l - 1]) l++;
					while (l < r && nums[r] == nums[r + 1]) r--;
				} else if (temp < 0) {
					l++;
				} else {
					r--;
				}
			}
		}

		return target;
	}
};
```

### 解法二：排序 + 哈希表

排序后固定 `i`，再从左到右扫描第二个数 `nums[n]`。每轮用哈希集合保存此前扫描过的值，查询是否出现过 `-(nums[i] + nums[n])`。查询必须在插入当前值之前进行，保证同一个元素不会被重复使用。

1. 排序数组，并跳过重复的 `i`。
2. 每个 `i` 开始时清空 `seen`，从 `n = i + 1` 开始扫描。
3. 计算所需值 `need = -(nums[i] + nums[n])`；若 `seen` 中存在 `need`，记录三元组并跳过后续重复的 `nums[n]`。
4. 将当前 `nums[n]` 插入 `seen`，继续扫描。

**复杂度**：平均时间 $O(n^2)$，额外空间 $O(n)$。

## 易错点

| 坑点 | 后果 | 处理方式 |
|------|------|----------|
| 找到和为 `0` 后没有移动指针 | 重复记录或循环不前进 | 双指针都移动，再跳过重复值 |
| 只处理指针去重，未处理 `i` 去重 | 同一组三元组可能重复出现 | 循环开始时比较 `nums[i]` 与 `nums[i - 1]` |
| `nums[i] > 0` 的剪枝放在内层 | 重复判断，控制流不清晰 | 固定 `i` 后立即判断并 `break` |
| 假设数组长度总大于 `3` | 长度不足时边界处理不稳妥 | 工程代码先判断 `nums.size() < 3` |
| 对 `vector` 使用 `.head()` 或 `.length()` | 编译错误 | 使用下标，或用 `.begin()` / `.size()` |
| 哈希集合未在每个 `i` 开始时清空 | 不同固定值之间错误复用状态 | 将 `seen.clear()` 放在 `i` 循环体开头 |
| 哈希扫描时先插入再查询 | 当前元素可能被当作配对元素复用 | 先查 `need`，再插入 `nums[n]` |
| 哈希解法只跳过重复的 `n`，没有跳过重复的 `i` | 同一三元组仍可能由不同的 `i` 产生 | `i` 与命中后的 `n` 都需要去重 |
| `unordered_map` 直接调用 `insert(nums[n])` | 参数类型不匹配 | 这里只需要值集合，使用 `unordered_set<int>` |
| 循环条件直接用 `nums.size() - 2` | `size()` 是无符号数，短数组可能下溢 | 先做长度检查，或转换为有符号下标后计算边界 |

## 解法对比

| 解法 | 时间复杂度 | 额外空间 | 去重难度 | 推荐度 |
|------|-----------|---------|---------|--------|
| 排序 + 双指针 | $O(n^2)$ | $O(1)$* | 低 | 首选 |
| 排序 + 哈希表 | 平均 $O(n^2)$ | $O(n)$ | 中 | 可用于练习哈希 |
| 三重循环 | $O(n^3)$ | $O(1)$ | 低 | 仅作暴力对照 |

\* 通常不计排序内部栈和输出空间。

## 复习提示

先排序以便剪枝和相邻去重；固定一个数后，优先用左右指针夹逼剩余两数。
