# 11. 盛最多水的容器

- 题目链接：[LeetCode 11](https://leetcode.cn/problems/container-with-most-water/)
- 难度：中等
- 标签：双指针、数组、贪心

## 题意概括

给定一个长度至少为 2 的非负整数数组 `height`，其中 `height[i]` 表示位置 `i` 处垂线的高度。选择两条垂线作为容器边界，返回容器能够盛放的最大水量。容器不能倾斜。

## 核心思路

使用双指针分别从数组两端向中间移动。两条边界能盛水的高度由较短的板决定，面积为两板间距乘以较短板的高度。每次计算当前面积后移动较短的一侧：移动较高的一侧只会缩短宽度，且容器高度仍受较短板限制，不可能得到更大的面积；移动较短的一侧才有机会遇到更高的板。

## 解题步骤

1. 若数组为空，返回 `0`；否则初始化左指针 `left = 0`、右指针 `right = height.size() - 1`，并令最大面积为 `0`。
2. 当 `left < right` 时，计算 `(right - left) * min(height[left], height[right])`，并更新最大面积。
3. 若左侧较短，则将 `left` 右移；否则将 `right` 左移。循环结束后返回最大面积。

## 复杂度

- 时间：$O(n)$，每轮至少移动一个指针，最多遍历数组一次。
- 空间：$O(1)$，只使用常数个额外变量。

## 我的代码

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int maxArea = 0;
        int head = 0;
        int end = height.size() - 1;

        while (head < end) {
            int currentArea = (end - head) * min(height[head], height[end]);
            if (maxArea < currentArea) {
                maxArea = currentArea;
            }

            if (height[head] < height[end]) {
                ++head;
            } else {
                --end;
            }
        }

        return maxArea;
    }
};
```

## 标准代码（正确且最优）

```cpp
class Solution {
public:
    int maxArea(vector<int>& height) {
        int left = 0;
        int right = static_cast<int>(height.size()) - 1;
        int maxArea = 0;

        while (left < right) {
            int currentArea = (right - left) * min(height[left], height[right]);
            maxArea = max(maxArea, currentArea);

            if (height[left] < height[right]) {
                ++left;
            } else {
                --right;
            }
        }

        return maxArea;
    }
};
```

## 易错点

- 必须移动较短的一侧；移动较高的一侧不会改善高度上限，只会让宽度变小。
- `vector` 使用 `size()` 获取元素数量，没有 `length()` 成员函数。
- `size()` 返回无符号类型，空数组时直接计算 `size() - 1` 会下溢；本题约束保证数组长度至少为 2，但防御性代码仍可先检查空数组。
- 本地编译时，`vector` 和 `min`、`max` 分别需要相应的标准库声明（通常包含 `<vector>` 和 `<algorithm>`）；LeetCode 会提供题目运行环境。

## 复习提示

从两端夹逼，每次移动短板，因为短板决定当前容量，只有短板变高才可能弥补宽度减少。
