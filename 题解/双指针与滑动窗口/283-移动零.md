# 283. 移动零

- 题目链接：[LeetCode 283](https://leetcode.cn/problems/move-zeroes/)
- 难度：简单
- 标签：数组、双指针

## 题意概括

给定整数数组 `nums`，将所有 `0` 移到数组末尾，同时保持非零元素的相对顺序。要求原地修改数组，不复制数组。

## 核心思路

使用快慢指针。快指针遍历数组寻找非零元素，慢指针 `slow` 标记下一个非零元素应放置的位置。找到非零元素后，将它与慢指针位置交换，再让慢指针前进。这样非零元素保持原有相对顺序，零自然留在末尾。

## 解题步骤

1. 初始化慢指针 `slow = 0`。
2. 快指针 `fast` 从左到右遍历数组。
3. 当 `nums[fast] != 0` 时，将它与 `nums[slow]` 交换，然后递增 `slow`。

## 复杂度

- 时间：$O(n)$，快指针遍历数组一次。
- 空间：$O(1)$，原地交换，只使用常数额外空间。

## 我的代码

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int size = nums.size();
        if (size <= 1) {
            cout << "[" << nums[0] << "]" << endl;
        }

        int slow = 0;
        int fast = 0;
        for (; fast < size; fast++) {
            if (nums[fast] != 0) {
                swap(nums[slow], nums[fast]);
                slow++;
            }
        }

        cout << "[";
        if (size != 1) {
            for (int i = 0; i < size - 1; i++) {
                cout << nums[i] << ",";
            }
            cout << nums[size - 1] << "]" << endl;
        }
    }
};
```

## 标准代码（正确且最优）

```cpp
class Solution {
public:
    void moveZeroes(vector<int>& nums) {
        int slow = 0;
        for (int fast = 0; fast < static_cast<int>(nums.size()); ++fast) {
            if (nums[fast] != 0) {
                if (slow != fast) {
                    swap(nums[slow], nums[fast]);
                }
                ++slow;
            }
        }
    }
};
```

## 易错点

- 快指针循环条件应为 `fast < size`，避免访问数组末尾之外的位置。
- 找到非零元素后慢指针必须前进，否则后续元素会覆盖同一个位置。
- `slow == fast` 时不必交换；跳过自交换可以减少不必要写入。
- 题目保证数组至少有一个元素；一般写法仍可自然处理空数组，不需要访问 `nums[0]`。
- 个人代码中的 `cout` 只是调试输出，标准提交应删除；边界分支访问 `nums[0]` 也依赖题目非空约束。

## 复习提示

快指针找非零，慢指针接应并交换；每找到一个非零元素，慢指针就前进一步。
