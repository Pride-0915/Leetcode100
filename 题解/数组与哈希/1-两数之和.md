# 1. 两数之和

- 题目链接：[LeetCode 1](https://leetcode.cn/problems/two-sum/)
- 难度：简单
- 标签：数组、哈希表

## 题意概括

给定整数数组 `nums` 和整数 `target`，返回两个不同下标，使这两个位置的数之和等于 `target`。题目保证每组输入恰有一个有效答案。

## 核心思路

个人代码枚举所有下标对，找到满足条件的组合后立即返回。标准解法用哈希表保存已遍历数值及其下标：遍历当前数时，先查找 `target - nums[i]` 是否已出现，找到即可返回两个下标；否则保存当前数值和下标。

使用 `find()` 查询补数，避免 `operator[]` 在缺少键时插入默认值。`try_emplace()` 只在键不存在时插入，保留该数值最早出现的下标。

## 解题步骤

1. 个人解法：枚举 `i`，再枚举 `j > i`，检查 `nums[i] + nums[j]` 是否等于 `target`。
2. 标准解法：创建数值到下标的哈希表，并预留与数组长度相近的容量。
3. 从左到右遍历，先用 `find()` 查补数；未找到时用 `try_emplace()` 记录当前数值和下标。

## 复杂度

- 个人代码：时间 $O(n^2)$，空间 $O(1)$。
- 标准代码：平均时间 $O(n)$，空间 $O(n)$；哈希冲突严重时单次查找最坏可达 $O(n)$。

## 我的代码

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        int numSize = nums.size();
        for (int i = 0; i < numSize; i++) {
            for (int j = i + 1; j < numSize; j++) {
                if (nums[i] + nums[j] == target) {
                    return {i, j};
                }
            }
        }

        throw runtime_error("No valid pair found");
    }
};
```

## 标准代码（正确且最优）

```cpp
class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> indexByValue;
        indexByValue.reserve(nums.size());

        for (int i = 0; i < static_cast<int>(nums.size()); ++i) {
            int complement = target - nums[i];
            auto it = indexByValue.find(complement);
            if (it != indexByValue.end()) {
                return {it->second, i};
            }

            indexByValue.try_emplace(nums[i], i);
        }

        return {};
    }
};
```

## 易错点

- 必须保证两个下标不同，因此查询当前数的补数应在插入当前数之前进行。
- `unordered_map::operator[]` 读取不存在的键会插入默认值；只读查找应使用 `find()` 或 `at()`。
- `find()` 未命中时返回 `end()`；`end()` 是尾后哨兵，不能解引用，必须先比较。
- `try_emplace()` 是 C++17 起可用的插入方式；题目保证有解，因此最后的空返回只作防御性兜底。
- 本地编译需包含 `<unordered_map>`、`<vector>` 及异常相关头文件；LeetCode 环境通常已处理常用声明。

## 复习提示

遍历到当前数时先查 `target - 当前数`，再把当前数及下标放入哈希表。
